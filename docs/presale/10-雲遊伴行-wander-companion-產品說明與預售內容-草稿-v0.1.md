## 3. 產品概述

雲遊伴行（WanderCompanion）是 Wonderland.center（水月道場）規劃中的高齡長者虛擬旅遊陪伴服務。行動不便的長者透過 XR 或 360° 場景「出遊」，由會說台語、客語、粵語、國語等語言、且會放慢語速的 AI 導遊依長者的生命經歷與體力安排行程，必要時拿長者小時候看過的舊車站之類的地方做對照解說；旅程結束後整理成附語音祝福的「數位漫遊手札」，同步給家屬。外地子女也可以用手機或平板加入同一個景點同遊。

服務的核心是分工：AI 負責內容與規模化，真人志工負責情感與安全。長者按下求助或系統偵測到疲勞時，AI 導遊會退居靜音，由遠端志工以視訊接手；生命故事傾聽、敏感回憶、設備教學與家屬溝通也都由真人負責。穿戴裝置的訊號只用來調整旅程節奏，**不作醫療診斷，本產品也不是醫療器材**。

## 4. 核心特性與功能（可驗證者優先）

**AI 軌道**

2. **沉浸式場景（FEAT-AI-02）**：360° 全景、歷史風貌、雙耳空間音訊；預留氣味與震動外設介面。
3. **多方言自適應導遊（FEAT-AI-03）**：台語、客語、粵語、國語及多國語言（範圍 [待確認]）；語速隨長者反應降速；對比式解說。
4. **疲勞感知（FEAT-AI-04）**：語調停頓、注視點、手環心率 → 偵測疲勞，自動進入「休整茶歇」模式。**非醫療用途。**

6. **旅程手札（FEAT-AI-06）**：自動彙整片段，生成附語音祝福的圖文手札，同步家屬 App。

7. **一鍵求助與主動降級（FEAT-HUM-01）**：觸發警示時 AI 導遊靜音，遠端志工視訊切入。
8. **生命故事共同標註（FEAT-HUM-02）**：志工標記長者情感禁區（例如戰亂記憶、逝親場景），修正後續內容。
9. **親友同遊包廂（FEAT-HUM-03）**：外地子女以手機／平板連線共遊。
10. **志工點數（FEAT-HUM-04）**：陪伴時數回傳 `platform-resource-points-conversion` 累積公益點數。

**長者友善與隱私**

11. 對比度 ≥ 7:1、字體 ≥ 24pt、觸控目標 ≥ 64×64 px、免觸控語音操作、語速 70%–80%、瞬移移動與柔和黑屏過渡（以 WCAG 2.1 AAA 準則為設計目標，未經認證 [待確認]）。

## 6. 差異化定位

**同法人（Wonderland.center）相鄰產品**

- **vs. 選擇預演（ChoiceRehearsal）**：兩者都服務高齡族群並有真人介入，但雲遊伴行是**休閒與陪伴**的虛擬旅遊；選擇預演是安寧緩和醫療意願的**教育與決策輔助**。雲遊伴行的生理感測只調節旅程節奏，不涉及醫療決策。
- **vs. 數位回聲（Digital Echo）**：數位回聲重現已故者；雲遊伴行陪伴在世長者，AI 導遊是導覽角色，不模仿任何真實人物 [待確認]。志工可標記「逝親場景」為情感禁區，與數位回聲的方向相反，兩者不應交叉推銷 [假設]。

**跨法人**

- **vs. VeilProof 隱證、AllView FHE Social**：無功能重疊；VeilProof 的「沙盤／視覺化」與本產品 XR 場景用途完全不同。
- **vs. AEGIS 產品**：無功能重疊。
- **共用平台**：`platform-resource-points-conversion`、`platform-amoeba-unit-template` 為協作依賴，不改變本產品歸屬 Wonderland.center。

**相對於一般 VR 旅遊內容**：差異在長者專屬的語速、方言、防暈眩與高對比設計，疲勞感知自動休息，以及真人志工可隨時接手與家人同遊。

## 功能

### AI 模組
- `FEAT-AI-01` 個人化動態行程：依生命史、體力量表、文化記憶偏好編排。
- `FEAT-AI-02` 沉浸式多感官：360° 全景、歷史風貌、雙耳空間音訊；預留氣味與震動外設介面。
- `FEAT-AI-03` 自適應語音導遊：台語、客語、粵語、國語及多國語言（範圍 [待確認]）；語速隨反應調整；對比式解說。
- `FEAT-AI-04` 疲勞感知（非醫療）：語調停頓、注視點、藍牙手環心率 → 觸發「休整茶歇」模式。
- `FEAT-AI-05` 內容安全過濾：閃爍刺激、強烈墜落感、悲傷歷史創傷場景。
- `FEAT-AI-06` 旅程記憶明信片：附語音祝福之「數位漫遊手札」，同步家屬 App。

### 真人護航模組
- `FEAT-HUM-01` 一鍵求助與主動降級：AI 導遊靜音，遠端志工視訊切入。
- `FEAT-HUM-02` 生命故事共同標註：志工標記情感禁區，修正後續生成。
- `FEAT-HUM-03` 親友同遊虛擬包廂：外地子女以手機／平板共遊。
- `FEAT-HUM-04` 志工點數結算：時數回傳 `platform-resource-points-conversion`。

    志工工作台：感知狀態看板、緊急介入（Takeover）、家屬視訊橋接

## 長者友善設計（以 WCAG 2.1 AAA 準則為設計目標；未經第三方認證 [待確認]）

1. 視覺：文字對比度 ≥ 7.0:1；字體 ≥ 24pt；觸控目標 ≥ 64 × 64 px；CIS 色系（月光白 `#F4F7F6`、玄墨黑 `#1A1E24`、澄心金 `#D4AF37`）。
2. 語音優先：核心功能可純語音操作；導遊預設語速為常人 70%–80%。
3. 防暈眩與認知保護：禁止強制位移與劇烈旋轉；移動採瞬移配柔和黑屏過渡；限制單景點資訊密度。

## 隱私與安全邊界（依台灣個資法設計；合規確認 [待確認]）

- **非醫療性質隔離**：不得在 UI 或日誌宣稱具醫療診斷能力。
- **生理訊號本地抽象化**：語音特徵與心率於本地 Gateway 轉為抽象數值（如 `FatigueIndex`）；原始生物特徵不得未加密上雲。
- **志工通話隱私遮蔽**：自動模糊居家背景、遮蔽病歷與私人物品。
